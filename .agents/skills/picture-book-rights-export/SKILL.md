# 工程10: 権利・開示・書き出し

## 担当

- **人:** 権利、クレジット、AI 開示、書き出し形式（必須）

## 手順

1. 使用素材・フォント・参照の権利を `rights.md` に列挙する。
2. AI 使用範囲（文の下書き、参照画像の有無など）を短く開示文にする。
3. 最終判断者を再確認する。
4. 出力形式（印刷／電子／読み聞かせ）に合わせて書き出す。

## 完了条件

- `rights.md` が空でない
- 開示方針と最終判断者が明記されている
- 成果物一式の置き場が分かる

## やらないこと

- 権利曖昧なまま公開・納品する
