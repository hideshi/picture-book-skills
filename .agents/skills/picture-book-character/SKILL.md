# 工程5: キャラシート

状態は `_shared/process-state.md` に従う。

## 担当

- **人:** 見た目ルールの固定と崩しの差し戻し、ベース参照の採否
- **AI:** 記述の整理・チェックリスト化は可。デザイン決定は人

## 前提

brief 以降いつでも開始可。rough / final-art の確定前までに揃える（キャラ不在なら N/A）。

## 手順

1. 主要キャラごとに顔・体・色・持ち物・禁止バリエーションを書く。
2. 「変えてよいもの／変えてはいけないもの」を分ける。
3. **ビジュアル・ベースライン参照:** キャラが存在するなら、人のスケッチ・写真参照・採用した visual-refs など、見た目の基準を紐づける。無ければ理由つきで例外を記録する。
4. キャラが物語上いない／抽象のみなら `character.md` に **N/A** と理由を書き、確定扱いにしてよい。
5. ラフ工程に渡す一行サマリを付ける。

## 完了条件

- `character.md` があり、主要キャラが揃っている **または** N/A が理由つきで記録されている
- キャラありの場合、ベースライン参照（または例外記録）がある
- final-art 前は状態が `確定`（または N/A 確定）

## やらないこと

- 頁ごとに髪型・服・耳の形が変わるのを見逃す
- キャラありなのに参照も例外記録もなく本番へ進む
