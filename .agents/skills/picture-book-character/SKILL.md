# 工程5: キャラ・世界観シート

状態は `_shared/process-state.md` に従う。

## 担当

- **人:** 人物・場所・小道具の見た目ルール固定、ベース参照の採否
- **AI:** 記述の整理・チェックリスト化は可。デザイン決定は人

## 前提

brief 以降いつでも開始可。rough / final-art の確定前までに揃える（キャラ不在なら N/A）。

## 手順

1. brief のビジュアル一貫性ポリシー（`_shared/visual-consistency.md`）を読む。
2. 主要キャラごとに顔・体・色・持ち物・禁止バリエーションを書く。
3. 「変えてよいもの／変えてはいけないもの」を分ける。
4. **ビジュアル・ベースライン参照:** キャラが存在するなら、人のスケッチ・写真参照・採用した visual-refs など、見た目の基準を紐づける。無ければ理由つきで例外を記録する。
5. 固定する舞台・家具があれば場所シート、キー小道具があればプロップ・アンカーを登録する。輪郭、部品、色、相対サイズ、登場頁、参照ファイルと版を書く。
6. キャラが物語上いない／抽象のみなら人物欄を **N/A** にしてよい。場所・小道具も該当しない項目ごとに N/A と理由を残す。
7. rough に渡す一行サマリと、添付すべき基準参照一覧を付ける。

## 完了条件

- `character.md` があり、人物・場所・キー小道具の該当項目が揃っている **または** N/A が理由つきで記録されている
- キャラありの場合、ベースライン参照（または例外記録）がある
- 固定する場所・キー小道具がある場合、Anchor の参照と固定要素がある
- final-art 前は状態が `確定`（または N/A 確定）

## やらないこと

- 頁ごとに髪型・服・耳の形が変わるのを見逃す
- キャラありなのに参照も例外記録もなく本番へ進む
- キー小道具を頁ごとのプロンプト文だけで再定義する
