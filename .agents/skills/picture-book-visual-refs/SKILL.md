# 工程7: ビジュアル参照（任意）

## 担当

- **AI:** 構図・小物・光の参照候補
- **人:** 採用／不採用、トレース方針のメモ

## いつ使うか

ラフで詰まったときだけ。必須工程ではない。

## 手順

1. 必要な頁・不足（構図、小物、背景）を特定する。
2. AI で候補を出し、人が選ぶ。
3. 採用したものの利用方針（参照のみ／部分トレース不可、など）を書く。
4. ファイルを `visual-refs/` に置き、ページ番号と紐づける。

## 完了条件

- 使ったなら方針メモがある。使わなければこの工程スキップでよい

## やらないこと

- 参照を最終イラストとして納品する（別方針を brief で明示した場合を除く）
