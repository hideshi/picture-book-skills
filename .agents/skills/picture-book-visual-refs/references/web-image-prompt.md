# Web画像生成プロンプト規約

brief の画像運用モードが `Webプロンプト手渡し` のときに使う。エージェントは
プロンプトと添付一覧を作り、Webサービスへの入力と画像生成はユーザーが行う。

## 提示順

1. **用途:** 作品名、頁ID、参照／ラフ／本番候補の別
2. **必須添付:** ファイル名、版、何の正本か。人物、場所、キー小道具のうち当該頁に必要なものだけ
3. **変えてはいけない要素:** brief と character の固定項目
4. **場面:** pagination / prose に基づく人物、行動、感情、画角、光
5. **変えてよい要素:** ポーズ、表情、画角など、その頁で許容する範囲
6. **排除事項:** 意図しない文字・擬音・フキダシ・記号・看板・背表紙文字・実在ロゴ、不要な人物や家具、基準にない小道具部品
7. **出力:** 縦横比、必要な余白、候補数。後工程で文字を置く場合は安全域

## 出力テンプレート

```text
【用途】<作品 / 頁ID / 成果段階>

【必須添付】
- <path@version>: <人物／場所／小道具の正本>

【固定】
- <舞台、外見、左右配置、キー小道具の構造>

【場面】
<誰が、どこで、何をし、どんな感情か。画角と光。>

【許容する変化】
- <ポーズ、表情、画角など>

【排除】
- 意図しない文字、擬音、フキダシ、記号、看板、背表紙文字、実在ロゴ
- <案件固有の不要物や禁止要素>

【出力】
<比率、余白、安全域、候補数>
```

サービス固有の構文は案件メモに残し、この規約の正本へ固定しない。生成後は
ファイル、使用プロンプト、添付した正本の版、人の採否を頁IDへ紐づける。
