# ビジュアル一貫性ポリシー

作品ごとの一貫性は「全部同じにする」ためではなく、意図しない変化と意図した演出を
区別するために記録する。brief で人が決め、pagination / character / rough /
final-art / readthrough が同じ正本を参照する。

## brief に残す項目

各項目を `固定` / `可変` / `N/A` のいずれかにし、固定または条件つき可変なら
具体値を書く。

| 項目 | 記録する内容 |
| --- | --- |
| 空間・舞台 | 基本舞台、家具・背景要素の必須／許容／禁止、場面転換する頁または条件 |
| キャラクター | キャラシート参照、固定する顔・体格・服・色、許容する変化 |
| キー小道具 | 名称、Anchor のファイル／版、固定する輪郭・部品・色、登場頁。誤認しやすいものは素材・構造も記録 |
| ルック／色調 | 固定が必要なら基準画像のファイル／版、画材感、紙色、彩度・明暗・コントラスト、変化を許す頁または条件。不要なら N/A |
| 画面配置 | 左右位置を固定するか、入れ替えを許す条件、視線・動線上の理由 |
| 画像内文字 | 意図しない文字・擬音・記号・ロゴの排除、意図的な文字の内容と制作方法 |

さらに次を残す。

- **正本参照:** 採用画像または図のパスと版。文章だけで十分ならその理由
- **参照の役割と優先順位:** 構図、人物、場所、小道具、ルック／色調のどれを拘束する参照か。参照同士が衝突したときに何を優先するか
- **許容差:** 表情、ポーズ、光、画角、衣装替えなど変えてよい範囲
- **意図した例外:** 頁、理由、人の判断。例外は違反として扱わない
- **未決事項:** 未定のまま下流へ渡す項目と、その決定期限

## 下流での扱い

1. pagination は可変項目と例外を頁へ割り当てる。
2. character / rough は人物・場所・小道具の Anchor を作り、参照先を固定する。ルック／色調を固定する案件では、採用できる画像が揃った段階で基準画像を選び、版を記録する。
3. rough は人物の姿勢、必要な家具、小道具の所有者・位置・状態を頁間で照合する。
4. final-art は頁別に準拠／例外／要修正を記録する。ルック／色調を固定する案件では、直前頁の生成結果だけを次頁の唯一の基準にしない。新しい画像を正本にする場合は、人が採用し版を付け、影響頁を再確認する。
5. readthrough はポリシーから案件固有チェックを作り、A と B の両方で照合する。
6. 正本を差し替えたら、影響する下流成果物を `要再確認` にする。

画像内文字を許可しても、画像生成モデルに正確な文字組みを任せるとは限らない。
採用文言は prose 等の文字正本で管理し、最終文字組みの方法を別に決める。
