# 工程6: ラフ

状態は `_shared/process-state.md` に従う。

## 担当

- **人:** 全頁ラフ（必須）
- **AI:** 構図アイデアの言葉出しは可。ラフ自体の代替にはしない

## 前提

### 開始条件

`prose.md` と `character.md`（または N/A）の **下書き以上** があれば開始してよい。pagination とも反復してよい。

### 確定条件（final-art へ進む前）

prose・character（または N/A）・rough がいずれも **確定**。

## 手順

1. 全頁サムネ／ラフを描く。
2. 各頁に「絵主役／文主役」を印する。
3. キャラシート違反を潰す。
4. めくりの間が死んでいる頁を直す。
5. 詰まった頁は `picture-book-visual-refs` を **ラフ途中で**呼んでよい（brief の AI 範囲を確認）。
6. ページ表・本文と矛盾したら pagination / prose へ戻し、該当成果物を `要再確認` にする。
7. 任意で readthrough **相 A**（ラフ＋仮文）を挟んでよい。

## 完了条件

- 全頁ラフがあり、`rough-notes.md` に頁コメントまたはファイル参照がある
- final-art に進むなら状態が `確定`（開始時点では下書きでよい）

## やらないこと

- ラフなしで本番塗りに進む
- 「rough を開始できた」ことを「prose/character/rough 確定済み」と混同する
