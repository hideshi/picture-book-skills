# 工程6: ラフ

状態は `_shared/process-state.md` に従う。

## 担当

- **人:** 全頁ラフ（必須）
- **AI:** 構図アイデアの言葉出しは可。ラフ自体の代替にはしない

## 前提

### 開始条件

`prose.md` と `character.md`（または N/A）の **下書き以上** があれば開始してよい。pagination とも反復してよい。

### 確定条件（final-art へ進む前）

prose・character（または N/A）・rough がいずれも **確定**。

## 手順

1. 全頁サムネ／ラフを描く。
2. 各頁に「絵主役／文主役」を印する。
3. **舞台・空間の一貫性チェック:** 主要な舞台（部屋・家具・ロケーション）の基本設定を固定し、ページ間で和洋や場所の勝手なブレ（屋外ベンチの混入等）を排除する。
4. **キー小道具の基準画固定:** 物語の核となる重要な道具・機械・アイテムは基準画（Anchor）を定め、全編で構造・パーツの一貫性を守る。
5. **製本見開きペアリング確認:** 物理的な製本構造（扉p1単独 → 見開きp2-3, p4-5... → 閉じ単独）を前提に、同時に視界に入る対面ページ同士の調和・呼吸を確認する。
6. キャラシート違反を潰す。
7. めくりの間が死んでいる頁を直す。
8. 詰まった頁は `picture-book-visual-refs` を **ラフ途中で**呼んでよい（brief の AI 範囲を確認）。
9. ページ表・本文と矛盾したら pagination / prose へ戻し、該当成果物を `要再確認` にする。
10. 任意で readthrough **相 A**（ラフ＋仮文）を挟んでよい。

## 完了条件

- 全頁ラフがあり、`rough-notes.md` に頁コメントまたはファイル参照がある
- final-art に進むなら状態が `確定`（開始時点では下書きでよい）

## やらないこと

- ラフなしで本番塗りに進む
- 「rough を開始できた」ことを「prose/character/rough 確定済み」と混同する
