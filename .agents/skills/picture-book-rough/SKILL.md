# 工程6: ラフ

## 担当

- **人:** 全頁ラフ（必須）
- **AI:** 構図アイデアの言葉出しは可。ラフ自体の代替にはしない

## 前提

`prose.md` と `character.md` がある（並行開始は可だがラフ確定前に両方必要）。

## 手順

1. 全頁サムネ／ラフを描く。
2. 各頁に「絵主役／文主役」を印する。
3. キャラシート違反を潰す。
4. めくりの間が死んでいる頁を直す。

## 完了条件

- 全頁ラフがあり、`rough-notes.md` に頁コメントまたはファイル参照がある

## やらないこと

- ラフなしで本番塗りに進む
